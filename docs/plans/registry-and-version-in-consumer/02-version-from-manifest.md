# 02: Версия движка — из манифеста пакета

**What to build:** `gitmark version` сообщает версию поставленного пакета (0.2.x), а не
зашитую константу `0.1.0`; та же версия уходит в `meta` индекса.

**Blocked by:** 01 (общий резолв корня пакета).

- [ ] В payload появляется `.omp/package.json` с версией и уезжает потребителю вместе с
      пакетом (источник каталога — `path: ".omp"`)
- [ ] `gitmark version` читает версию из корня пакета; если манифеста нет — прежняя
      константа, команда не падает
- [ ] В `meta` индекса пишется та же версия, что печатает `version`
- [ ] В потребителе с плагином `version` печатает версию плагина, в этом репо — версию из
      манифеста; в плоской установке поведение не ухудшилось
- [ ] Установка и апгрейд от манифеста не зависят (версию для upgrade задаёт запись
      каталога) — подтверждено прогоном `omp plugin upgrade` или явной ссылкой на
      проверку из архивного плана
- [ ] Описание `version` в `.omp/skills/kb-search/SKILL.md` и
      `docs/services/gitmark-cli/README.md` обновлено; `gitmark lint` чистый, индекс
      пересобран
