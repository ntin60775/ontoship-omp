# 01: Команда инициализации — управляемый блок в AGENTS.md

**What to build:** свежий потребитель получает entry point одной идемпотентной командой
пакета: она ведёт управляемый блок в `AGENTS.md`, дополняет `.gitignore` и передаёт работу
`/onto-doc`, не затирая ничего вне блока.

**Blocked by:** None (can start immediately).

- [ ] В payload есть команда инициализации (`commands/init.md`) и шаблон блока
      (`.omp/templates/**`) — оба едут вместе с пакетом
- [ ] Правка секционная: блок между маркерами `<!-- BEGIN ontoship -->` и
      `<!-- END ontoship -->`; пять случаев — файла нет / файла нет, а блока нет / блок
      совпал с шаблоном / блок отличается (замена + предупреждение, что правки внутри блока
      не сохраняются) / маркеры непарные или битые (явная ошибка, без угадывания)
- [ ] Вне маркеров файл не меняется никогда; полной перезаписи `AGENTS.md` нет — ни флагом,
      ни режимом
- [ ] `.gitignore` дополняется только отсутствующими строками: `.gitmark/`, `*-map.html`,
      `.scratch/`
- [ ] Имена команд в блоке даны с префиксом плагина (`/ontoship:kb`, `/ontoship:onto-doc`,
      `/ontoship:ship`)
- [ ] Прогон на живой probe-папке: первый запуск создаёт/дополняет, повторный — no-op,
      текст вне блока сохранён
- [ ] `gitmark lint` чистый, индекс пересобран

**Отклонение (2026-09-14, при отгрузке).** Шаблон блока не вынесен отдельным файлом в
`.omp/templates/**`: файл вне каталогов навыков не адресуем из user-scope установки
(`skill://` резолвит только файлы внутри skill-каталогов, а путь кэша плагина не
хардкодится), тогда как текст команды omp загружает всегда. Шаблон инлайнится в
`.omp/commands/init.md` — одно место истины и ноль поисков пути. Реестр команд дополнен
секцией `/init`, таблицы перегенерированы (13 команд).
